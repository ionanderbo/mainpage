# Ion Ander Bolado — Personal Portfolio

Clean, lightweight personal website and project archive for **Ion Ander Bolado** (Biomedical Engineering, University of Deusto, Bilbao).

## Structure

- `index.html` — Main overview page with hero, bio snapshot, 2 featured projects, recent updates feed, and contact.
- `projects.html` — Dedicated page displaying the complete archive of current and past projects.
- `styles.css` & `animations.css` — Warm editorial alabaster & botanical teal design system.
- `config.js` — Supabase Project URL & Publishable Key configuration.
- `data.js` — Initial seed entries for bio snapshot, projects, and updates.
- `shared.js` — Data loader (Supabase + local fallback) and page renderers.
- `widgets.js` — Interactive CardioPatch ECG simulator, CT registration replay, and filters.
- `studio.js` — Private content panel opened exclusively via **`Ctrl + Alt + Shift + I`**.
- `supabase-schema.sql` — SQL setup for Supabase tables, Row Level Security, and file storage.
